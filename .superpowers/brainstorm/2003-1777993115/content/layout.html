Option A  Recommended

Flat scrollable list

All exercises as full cards in one continuous list. Current exercise glows with a border/badge. Completed exercises show logged sets. Upcoming show last session data. "＋ add" buttons between every exercise. "···" menu on each card for swap/skip/reorder.

Option C  Alternative
